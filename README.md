# Глава → курс · команда ЭШПОШМАКИ

Конвейер превращает главу книги по геологии или геофизике в проверенный учебный слой, а из слоя собирает демо-курс для новичка.

## Запуск

Нужны Windows, macOS или Linux, Python 3.11 или новее, а для роликов ещё ffmpeg.

```
cd pipeline
py -3 -m pip install -r requirements.txt -r video/requirements.txt
```

На Windows задайте `$env:PYTHONUTF8=1`, на Linux и macOS вместо `py -3` используйте `python3`.

**Одна команда на главу:**

```
py -3 run.py all --chapter train_latyshova
```

Команда выполняет нарезку на единицы, строит учебный слой, проверяет цитаты и числа, считает покрытие, делает маршрутизацию, задания, иллюстрации, экспорт в официальные схемы и курс. Результат появляется в `out/<глава>/index.html`.

- **Без ключей и без сети:** `py -3 run.py all --chapter train_latyshova --llm cache` — конвейер целиком пересобирает главу из закоммиченного кеша ответов моделей (`pipeline/.cache/llm`): единицы, слой, проверка, задания, курс, официальные JSON. Проверено: Кузнецов и Баренблатт пересобираются один в один; у Латышовой часть ответов в кеше от более раннего прогона, поэтому выходит 54 задания и 93% цитат вместо 62 и 97% в `deliverables/` (все требования ТЗ выполняются). Новая глава в этом режиме не соберётся — ей нужен профиль модели с ключом.
- Для сборки моделью нужен профиль с ключом (`.env.gemini` и другие, образец в `.env.example`). Без `.env` работает офлайн-заглушка `mock`: она проверяет, что конвейер запускается, но содержательного курса не даёт.
- Готовые курсы, собранные моделями, уже лежат в `deliverables/courses/`.

**Новая глава:**

1. Положите md с метками `<!-- page N -->` и добавьте запись в `pipeline/chapters.json`: страницы, заголовки начала и конца, типы трудности.
2. Запустите `run.py all --chapter <id>`.

**После правки факта в `out/<глава>/layer.json`:**

```
py -3 run.py verify --chapter <глава>
```

Команда заново сверяет цитаты и числа со страницами и пересобирает страницы курса.

- Ролик пересобирается из своей спецификации: `py -3 run.py video --spec video/specs/<ролик>.json`. Утверждения и страницы ролик берёт из слоя.
- Ручную правку записывайте в журнал: `py -3 run.py edit --chapter <глава> --node <id> --minutes 4 --what "…" --reason "…"`.

**Модуль проверки закладок:**

```
py -3 run.py review --package <папка>/package.json
```

Ответ появляется в `out/review/<id>/answer.json`.

**Модели.** Профили лежат в `pipeline/.env.<имя>`, образец — `.env.example`. Порядок задаёт `.env`:

```
LLM_PROFILES_BUILD=groq,gemini,qwen
LLM_PROFILES_CHAT=gemini,groq,qwen
```

Конвейер не привязан к поставщику: подходит любой OpenAI-совместимый `chat/completions`. Подробности — в `MANIFEST.md`.

**Сайт с чатом-тьютором и сборкой из загруженного файла (необязательно):**

```
py -3 server.py
```

Сайт открывается по адресу http://127.0.0.1:8770/.

## Как устроено

```
глава (md + PDF) → единицы → учебный слой (граф узлов, утверждения с цитатой и страницей)
                → проверка кодом (цитаты по тексту, числа, покрытие 100%)
                → маршрутизация (8 типов трудности → формат) → задания, карточки, иллюстрации
                → курс (HTML из слоя) + официальные JSON + ролик по спецификации сцены
```

Предметные знания лежат отдельно от движка, в `pipeline/domain/geology/`: глоссарий, заблуждения, чек-лист физики, стайлгайд и ударения. Для нового домена собирается новый пакет, код не меняется.
