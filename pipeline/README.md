# Глава → курс

Для запуска нужен Python 3.9 или новее. Команды выполняются из каталога с этим README.

## Студия подготовки

    python3 -m pip install -r requirements.txt
    python3 studio.py

Студия печатает локальный адрес для браузера. Загрузите PDF, DOCX, Markdown или TXT и при необходимости выберите диапазон. В ZIP входят автономный урок, загруженный источник, учебный слой и отчёты. Распакуйте ZIP и откройте index.html. PDF-страницы открываются рядом с курсом. Файлы студии хранятся в .studio/ или каталоге, заданном через --data.

PDF с текстовым слоем читается напрямую. Для страниц со сканами применяется OCR. На macOS нужен Swift с PDFKit и Vision. На Linux установите Poppler и Tesseract с языками rus и eng. Чтобы принудительно распознать выбранные страницы, отметьте опцию в форме или используйте --ocr в CLI. Текстовые документы без разметки страниц делятся на блоки. Формулы и подписи, полученные из OCR, стоит проверять по оригиналу.

Для полноценного режима задайте переменные среды при запуске студии. Ниже пример полного URL локального сервиса. Имя модели зависит от установленного сервиса.

    LLM_MODEL=MODEL LLM_ENDPOINT=http://127.0.0.1:8000/v1/chat/completions python3 studio.py

Если сервис требует ключ, задайте LLM_API_KEY в окружении. В режиме с моделью извлечённый текст передаётся настроенному сервису. Студия с выключенной моделью готовит черновик, сохраняя исходный текст и добавляя упражнения с пропуском.

## Автономная сборка

    python3 run_books.py "$HOME/Downloads/books md" "$HOME/Downloads/книги" ./courses

Откройте courses/index.html. Курсы работают без сервера. Ссылки на полные PDF указывают на файлы, выбранные при сборке. После переноса книг повторите сборку. Сохранение прогресса зависит от поддержки localStorage для локальных страниц в браузере.

Чтобы в Markdown сохранить нумерацию PDF, используйте метки вида `<!-- page 17 -->` на отдельных строках. Номера относятся к страницам PDF. Поддерживаются отдельные страницы и диапазоны через запятую.

    python3 build.py book.md 9-14,20-30 ./course --pdf book.pdf --title 'Название главы'

## Сборка с моделью

Параметр --endpoint задаёт полный адрес сервиса с поддержкой chat/completions и JSON-ответов. В сервис отправляются извлечённые блоки текста. Ключ, если нужен, читается из LLM_API_KEY. Сервис и модель выбирает оператор.

    python3 build.py book.md 17 ./course --pdf book.pdf --model MODEL --endpoint http://localhost:8000/v1/chat/completions

Модель получает фрагменты страницы или блока и названия нескольких предыдущих шагов и формирует объяснение, вопрос с выбором ответа и карточку по prompt.txt. Перед выводом проверяются идентификаторы, вхождение цитат в OCR, числовые значения объяснений и ключ задания. Смысловое соответствие, единицы измерения и верность OCR требуют отдельной проверки. Если ответ модели не проходит проверку, сборщик повторяет запрос с замечанием. Ошибка API останавливает сборку; используйте отдельный выходной каталог для каждого экспериментального прогона.

Для воспроизведения одного содержательного шага без подключения к сервису:

    python3 build.py "$HOME/Downloads/books md/train_latyshova.md" 107 ./example --responses example-response.json --title 'От измерений к эффективной толщине'

Файл примера содержит ответ, подготовленный в чате по примеру 54. Это один узел, и отчёт перечислит остальные фрагменты страницы как пропущенные. Без --responses и --endpoint сборщик переносит исходные блоки и составляет упражнения с пропуском слова.

## Результаты и проверка

* layer.json — узлы с привязками к фрагментам, вопросы и карточки. Локальная рабочая схема.
* coverage.json — связь каждого выделенного блока с узлом или причина пропуска. Автоматическое описание рисунка в распознанном формате FORMAT выделяется отдельно для сверки.
* index.html — курс, созданный только из учебного слоя.
* report.json — страницы, число блоков и заданий, время, статистика токенов при наличии ответа сервиса.

    python3 test_build.py

Фрагментация по страницам сохраняет контекст источника, но пока может разделять примеры на стыке страниц и включать конец соседнего параграфа. Рендер формул, граф предпосылок, проверка физических механизмов, видео и совместимость с официальной схемой организаторов требуют дальнейшей работы.

После правки объяснения или задания в layer.json выполните проверку по исходной книге и пересборку страницы:

    python3 rebuild.py book.md ./course/layer.json

Для слоя, построенного с принудительным OCR, пересборка снова распознаёт те же страницы.
